# MedCare 🏥
> Trabalho prático sistema hospitalar

O **Sistema de Informação Hospitalar** visa substituir registros manuais por uma plataforma centralizada e confiável para a gestão de rotinas médicas e administrativas[cite: 1]. A solução aplica conceitos avançados de Programação Orientada a Objetos (POO), arquitetura em camadas, persistência de dados e regras de negócio complexas para garantir a integridade das informações.
